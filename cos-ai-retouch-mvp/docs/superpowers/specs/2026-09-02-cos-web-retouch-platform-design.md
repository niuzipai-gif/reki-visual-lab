# COS AI 角色写真网页后期工作台设计

## 目标

把当前单图“上传—分析—生成”流程升级为纯网页 COS 后期工作台。用户不安装 Photoshop、不安装本地助手，也能在浏览器内完成常用人像后期、局部蒙版、图层管理、自动化预设和 PSD 分层导出。MiniMax 只负责把自然语言拆成结构化任务，不作为主要生图引擎。

## 用户闭环

1. 用户拖入一张或一组 COS 照片。
2. 工作台显示原图、可编辑图层、局部蒙版和右侧 COS 模块。
3. 用户可以手动调节，也可以输入“保留脸部身份、清理发丝、修复服装褶皱、做柔和电影感”等要求。
4. 编排器把要求拆成可确认的步骤；每一步显示作用范围、风险、使用的算子和是否需要云端 AI。
5. 浏览器即时执行基础调色和蒙版操作；局部重绘、分割、超分等重型能力通过独立的 ComfyUI-compatible 云端服务执行。
6. 每个步骤生成独立图层或图层组，用户可以隐藏、调透明度、重排、撤销或重新运行。
7. 导出 JPG/PNG 平面图、PSD 分层文件和可再次打开的 AURA 项目 JSON。

## 功能边界

### 首个可用版本

- 浏览器本地导入，不依赖邀请 token 或 MiniMax 才能打开编辑器。
- 原图锁定层、图层组、可见性、顺序、透明度和混合模式。
- 画布缩放、适应窗口、拖动画布、蒙版画笔、擦除、撤销。
- 曝光、对比度、饱和度、色温、锐度和电影感预设；调整以独立图层记录。
- COS 模块入口：面部精修、发丝整理、服装修复、身形边缘、背景清理、光影重塑、风格质感。
- 本地自动化预设：自然棚拍、清透日系、复古胶片、暗调电影；每个预设由可回退步骤组成。
- PSD 导出包含原图、修复/调色图层、蒙版、透明度、混合模式和步骤元数据；不承诺 Photoshop 原生曲线调整层。
- 失败时保留原图和已完成图层，不能把失败结果覆盖到原图。

### 后续接入

- MiniMax 文本编排器：结构化输出步骤 JSON，服务端校验后才能执行。
- ComfyUI-compatible 远程算子：分割、LaMa/扩散擦除、局部重绘、发丝/服装修复、超分、ControlNet/LoRA。
- 多图批处理、同一预设跨照片执行、任务队列和结果下载。
- 远程项目保存、分享和团队权限。

## 技术结构

```text
React/Vite 网页工作台
  ├─ Editor Store：图层、蒙版、参数、历史、编排步骤
  ├─ Canvas Renderer：Canvas 2D + WebGL 增强预览
  ├─ Operation Registry：基础调整、蒙版、AI 算子统一协议
  └─ Exporter：JPG/PNG + ag-psd PSD + AURA JSON

FastAPI / Render
  ├─ task/orchestrator API
  ├─ provider adapter（MiniMax 仅文本规划）
  ├─ ComfyUI-compatible AI job adapter
  └─ object storage / expiring assets
```

## 开源复用原则

- `ag-psd` 负责 PSD 读写，不自研 PSD 二进制格式。
- 现有蒙版画布保留为轻量渲染层，后续用 `perfect-freehand` 优化笔刷轨迹。
- 预览滤镜优先使用 Canvas/WebGL 能力；`glfx.js` 作为可替换的实时滤镜适配层。
- 经典工具只择优吸收 miniPaint 的 MIT 代码/思路，不嵌入它的整套 UI，避免状态和交互割裂。
- ComfyUI/IOPaint 等 AI 工具通过远程 HTTP 适配器隔离；IOPaint 已归档，不作为核心运行时依赖。
- 所有第三方依赖记录版本、许可证和来源，发布前生成依赖清单。

## 非功能要求

- 图片密钥和模型密钥只存在服务端环境，浏览器不接触 MiniMax key。
- 20MB 以内照片在常见桌面 Chrome 中可打开；大图采用预览缩放，导出保留原始尺寸上限。
- `prefers-reduced-motion` 下不播放装饰动画。
- 每次导出前校验 PSD 文件头、图层数、蒙版尺寸和可读性。
- 单元测试覆盖纯编辑器状态、蒙版归一化、调整计算、预设执行和 PSD 生成；Playwright 覆盖导入、修改、撤销、图层开关和导出。

## 验收标准

- 用户只打开网页并选择 JPG/PNG，即可进入编辑工作台，不需要 token、Photoshop 或本地程序。
- 至少一个真实调整（例如曝光/对比度）能改变预览和导出像素。
- 至少一个真实蒙版能限制调整区域，并能擦除、撤销。
- 图层可隐藏/显示、调透明度、重排；原图始终可恢复。
- 导出的 PSD 能被 `ag-psd` 再读回，包含不少于原图层、调整层和蒙版层。
- 现有后端测试、前端测试和生产构建保持通过。
