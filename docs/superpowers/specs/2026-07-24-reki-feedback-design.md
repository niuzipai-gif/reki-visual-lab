# Reki 反馈修复与品牌资产设计

> **状态：已被 `2026-07-24-reki-ai-style-workbench-design.md` superseded。** 品牌资产部分保留为历史记录；当前实现使用用户提供的角色 PNG 及透明方形裁切版。

## 目标

让 Reki 的标记编辑真正适合 coser 的精修流程：用户可以直接拖动任意已添加标记并通过可见控制点自由改变大小；标记视觉以高对比红色为主；原图对比能在同一画布内稳定切换；左上角品牌和 favicon 使用一套受参考图案启发、但完全重新绘制的 Reki 专属线稿。

## 交互设计

1. **拖动与缩放**
   - 所有未锁定标记均保持 Konva draggable。
   - 选中标记显示 Transformer/八方向控制点；拖动控制点改变该标记的归一化包围盒，保持点位在 0–1 范围内。
   - 路径、点、圆环、引线和标签统一按包围盒缩放；路径的内部点按包围盒比例变换，锚点随之移动。
   - 锁定图层只允许选择，不显示可操作缩放控制点。
   - 缩放、拖动都写入现有 reducer 历史记录与 IndexedDB 自动保存。

2. **颜色**
   - 默认标记线条/锚点使用 `#e5484d`，强调色使用 `#ff6b6b`，文字使用浅暖白以保证深色底图可读。
   - 预设生成的标记也统一使用红色系；用户在 Inspector 里仍可手动覆盖颜色。
   - 网格和品牌蛋黄色保留为 UI 状态色，不再作为标记主色。

3. **原图对比**
   - “原图对比”按钮切换 canvas 的背景源，而不是销毁标记层。
   - 有原图时显示未滤镜源图；无原图或源图加载失败时按钮禁用并给出可读状态。
   - 切换前后视图不改变当前选择、缩放、图层顺序或编辑历史。

4. **品牌资产（历史方案）**
   - 参考图案只用于提炼“谷穗、花环、软体角色、手绘线稿”的气质，不嵌入或裁剪用户截图。
   - 该历史方案原计划以 SVG 绘制图标；当前实现改用用户提供的 `public/brand/reki-character.png` 及透明方形 `reki-character-mark.png`，并由 SVG/favicon 包装引用。
   - TopBar、首页 ImportPanel、`index.html` favicon 与 README 预览统一使用新资产。

## 验证标准

- 单元测试覆盖包围盒缩放、锁定阻止缩放、原图切换保持标记层、红色默认样式和品牌资产引用。
- `npm test`、`npm run build`、`npm run test:sites`、`git diff --check` 全部通过。
- 本地桌面与 390px 手机端各完成一次拖动/缩放、原图对比和导出烟测。
- README 说明隐私、本地处理、快捷操作、部署和 GitHub 仓库位置。
